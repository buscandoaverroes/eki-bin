# Python dev tools for eki-bin
# Install via: make setup
#
# These are host-side tools only — nothing runs on the boards themselves.
# mpremote: MicroPython file management and REPL over USB serial (all boards)
# esptool:  ESP32-family firmware flashing (e.g. XIAO ESP32-C3; not needed for
#           the Pico, which uses picotool instead — see `make flash-esp32-c3`)
#
# EXACT pins, on purpose: `make setup` runs pip as you, and mpremote/esptool
# talk to hardware over serial. An open `>=` range means a compromised or
# broken new release installs itself on the next setup. Bump deliberately:
#   .venv/bin/pip install -U <pkg> && make test  →  edit the pin.

esptool==5.3.1
